# Как запустить скрипт

1. Установите [Tampermonkey](https://www.tampermonkey.net/) в браузер и разрешите запуск пользовательских скриптов.
2. В Tampermonkey нажмите **«Создать новый скрипт»**, замените весь код кодом по ссылке [последняя версия скрипта](https://raw.githubusercontent.com/LevMaltcev6/reject_pd/main/dist/return-pd.user.js) и сохраните. Если скрипт уже установлен, замените код в существующем скрипте.
3. Откройте Gmail или Яндекс Почту и перезагрузите страницу.
4. Нажмите **«Обращения по ПД · 0.2.6»** справа внизу.
5. Выберите шаблон обращения, заполните ФИО и email для ответа.
6. Выберите компании и проверьте получателей и текст в предпросмотре.
7. Выберите **«Отправлять автоматически»** и нажмите **«Отправить N писем»**. Оставьте вкладку открытой до завершения очереди. Для остановки нажмите **«Остановить»**.

Чтобы подготовить письма без автоматической отправки, выберите **«Только черновики»** и нажмите **«Подготовить N черновиков»**. После подготовки каждого письма отправьте его вручную или закройте редактор с сохранением черновика, затем нажмите **«Продолжить очередь»** в панели скрипта.
